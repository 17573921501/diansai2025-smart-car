# 智能小车系统技术文档

> 2025 年全国大学生电子设计竞赛参赛项目 · 基于 TI MSPM0G3507
> 本文档为项目工程解释文档，面向代码评审、复现维护与面试技术展示。

---

## 1. 项目概述

本项目是一套以 **TI MSPM0G3507（ARM Cortex-M0+，80MHz）** 为主控的智能小车系统，基于逐飞科技（SEEKFREE）MSPM0G3507 开源库（V3.0.8，底层为 TI 官方 SDK/DriverLib）进行二次开发。

系统围绕"**循迹行驶 + 视觉任务 + 云台描绘**"三条主线构建：

| 子系统 | 功能 |
| --- | --- |
| 运动控制 | TB6612 双路直流电机驱动、双路正交编码器测速、增量式 PI 速度闭环 |
| 循迹控制 | LF04 四路灰度传感器状态机解算 + 位置式 PD 差速控制，支持直角弯/大弯/微调/十字路口/丢线保护，按直角计数完成设定圈数后自动停车 |
| 视觉交互 | UART 与 OpenMV 双向通信，自定义帧协议下发任务命令、在线调节 LAB 颜色阈值 |
| 人机交互 | TFT180 彩屏 + 4 按键构成的两级菜单系统（发车/圈数/任务/调参） |
| 云台描绘 | X/Y 双舵机 PWM 云台，可按参数化轨迹描绘正弦、余弦、三角、方波 |
| 姿态感知 | IMU660RA 六轴 IMU（SPI 模式），Z 轴角速度低通滤波 + 积分解算方位角 |
| 调试链路 | 调试串口 printf、无线串口（VOFA 上位机波形/命令调参） |

### 3.1 主控与外设

- MCU：TI MSPM0G3507，主频 80MHz（`clock_init(SYSTEM_CLOCK_80M)`）
- 电机驱动：TB6612FNG（双 H 桥）
- 测速：两路增量式正交编码器（AB 相）
- 循迹：LF04 四路灰度/红外对管模块

## 4. 软件架构与执行模型

### 4.1 调度模型

系统采用 **"前后台 + 周期中断"** 的裸机调度模型，无 RTOS：

- **后台（主循环）**：低速任务——LED 心跳（500ms 翻转）、TFT 调试显示、printf 数据上报。
- **前台（中断）**：
  - `TIMG0_IRQHandler`（50ms）：`KEY_Scan()` 按键状态机；读取并清零编码器计数得到 50ms 速度脉冲数（M 法测速）。
  - `TIMG7_IRQHandler`（50ms）：运动控制核心。`start_car_flag == 1` 时执行 `Track_LF04()` 循迹解算与电机输出；直角弯标志有效时先延时 50ms 消抖再清零标志，防止同一直角弯重复计数；当直角弯计数达到 `laps_count * 4`（每圈 4 个直角）时调用 `TB6612_stop()` 停车。
  - `GROUP1_IRQHandler`：解析 GPIO 组中断索引与触发极性，分发到编码器四路 EXTI 回调，完成四倍频增减计数（依据两相电平同/异判断方向）。

### 4.2 初始化序列（user_init）

```
tft180_init            → TFT 显示
TB6612_init            → 电机 GPIO/PWM + 编码器 EXTI + 全局中断使能
pit_ms_init(TIMG0,50)  → 测速/按键扫描定时器
pit_ms_init(TIMG7,50)  → 循迹控制定时器
openmv_uart_init       → OpenMV 通信（FIFO + RX 中断）
gpio_init(LED)         → 状态灯
LF04_Init              → 循迹模块 GPIO
KEY_Init               → 按键 GPIO + 欢迎界面
```

## 5. 核心模块详解

### 5.1 电机驱动与速度闭环（wmm_lqtb6612.c）

- `Motor_Out(PWM_L, PWM_R)`：带符号 PWM 输入，符号决定 H 桥方向引脚组合，绝对值写入占空比（满量程 `PWM_DUTY_MAX = 10000`）。
- `Velocity_A/B(target, current)`：**增量式 PI** 速度环：

```
out(k) = out(k-1) + Ki·[e(k) - e(k-1)] + Kp·e(k)
```

  参数 `Kp = 20, Ki = 1`，输出限幅 ±6000。增量式结构天然抗积分饱和、便于与开环输出切换。Kd 变量保留未用。

### 5.2 循迹控制（LF04.c）

四路传感器状态编码为 4bit 状态字 `DH_state = (DH1<<3)|(DH2<<2)|(DH3<<1)|DH4`，查表得到偏差 `error`：

| 状态字 | 场景 | error | 附加动作 |
| --- | --- | --- | --- |
| 0000 | 十字路口 | 0 | 直行通过 |
| 0001 | 左直角弯 | -150 | 置 `zhijiao_flag=1`，计数+1 |
| 1000 | 右直角弯 | +150 | 置 `zhijiao_flag=2`，计数+1 |
| 0111 / 1110 | 左/右大弯 | ∓100 | — |
| 1011 / 1101 | 左/右微调 | ∓30 | — |
| 1001 | 直行 | 0 | — |
| 1111 | 丢线 | 保持直角转向 | 按 `zhijiao_flag` 延续 ±150 |

**位置式 PD 差速解算**（50ms 周期）：

```
output = kp·error + kd·(error - last_error)      // kp=15, kd=21, ki=0
left_pwm  = base_speed + output                   // base_speed=2500
right_pwm = base_speed - output                   // 限幅 ±8000
```

**直角弯处理**：直角特征（0001/1000）只在单侧传感器压线瞬间出现，故设置标志位并在下一次控制周期延时消抖后清除，保证一次直角只计数一次；进入直角后大概率丢线（1111），此时按标志维持满差速转向直至重新压线。

**自动停车**：`zhijaio_count >= laps_count * 4` 判定跑完设定圈数（每圈 4 个直角），切断电机输出。

### 5.3 OpenMV 视觉通信（openmv.c + key.c）

- 物理层：UART1，115200 8N1，RX 中断逐字节写入 FIFO（64 字节环形缓冲），置接收标志，主循环解析。
- 应用层自定义帧协议（由菜单系统发出）：

| 帧类型 | 长度 | 格式 |
| --- | --- | --- |
| 任务触发 | 4B | `AA 55 | cmd | cmd`（命令字节重复作校验，cmd ∈ '2'/'3'/'4'/'5'） |
| 阈值调节 | 7B | `AA 55 | A1 | is_white | index | value | checksum`，checksum = A1+is_white+index+value 取低 8 位 |

- `index` 0~5 对应 LAB 三通道的 min/max；`is_white` 区分白/黑两组阈值。默认阈值：
  - 白色：L[52,71] A[-19,-4] B[-125,10]
  - 黑色：L[4,22] A[-127,-6] B[-128,27]

### 5.4 菜单系统（key.c）

- 两级页面状态机：`PAGE_MAIN`（发车开关 R/S、圈数增减、Task2~5 命令下发、进入调参）与 `PAGE_ADJUST`（12 项 LAB 阈值 ±5 步进调节、黑白切换、返回）。
- 按键扫描挂接在 TIMG0（50ms），下降沿有效即触发，天然去抖；首次按键仅唤醒菜单。
- 所有页面切换与数值变更即时刷新 TFT180 并同步通过协议帧下发 OpenMV，实现**免改代码的现场调参**——这是赛场适应不同光照条件的关键设计。

### 5.5 舵机云台与波形描绘（servo.c）

- 双舵机 X/Y，50Hz PWM，脉宽 0.25ms(0°)~1.25ms(180°)，占空比 250~1250 线性映射。
- 描绘范围 X/Y 均限定 70°~110°（保护机构），单波形 400 个插值点、点间延时 10ms。
- 已实现参数化轨迹：`draw_sine_wave_float` / `draw_cosine_wave_float` / `draw_triangle_wave_float` / `draw_square_wave_float`，数学上 X 轴匀速扫过全程，Y 轴按波形函数在 ±0.4 幅度内调制，三角波采用 `2|2(t-¼) - ⌊2(t-¼)+½⌋| - 1` 解析式生成。

### 5.6 姿态解算（tuoluoyi.c）

- IMU660RA 读取加速度与角速度，Z 轴陀螺仪经灵敏度换算后做一阶低通：`gyro_z = 0.4·new + 0.6·last`。
- 方位角积分：`sum += gyro_z · 0.00102 · 3`（系数与调用周期强相关，若主循环周期改变需按比例重标定）。

### 5.7 调试链路（wirelessuart.c）

- 无线串口对接 VOFA 上位机：下行命令解析（如 `SP<float>` 速度环参数在线修改框架），上行 CSV 波形数据（目标/实际速度等），用于 PID 整定与运行观测。

## 6. 关键设计决策与工程取舍

1. **差速循迹选位置式 PD、速度环选增量式 PI**：循迹环对响应速度敏感，PD 提供足够阻尼抑制过冲且免去积分饱和风险；速度环要求无静差，增量式 PI 输出平滑、抗扰动恢复好。
2. **直角弯"特征状态 + 标志位 + 丢线保持"三段式处理**：解决四路传感器在直角处瞬时特征与随后丢线的固有缺陷，用最小传感器数量实现直角识别与计数。
3. **调参外置化**：LAB 阈值调节做成"菜单 + 协议帧"闭环，赛场光线变化时无需重新编译下载，显著缩短调试周期。
4. **中断只做最必要的事**：编码器 EXTI 回调仅做电平比较与计数；数据解析、显示刷新均放后台，降低中断延迟与嵌套风险。
5. **50ms 统一控制节拍**：测速、按键、循迹共用 50ms 节拍，简化时序设计；直角消抖直接复用下一节拍延时实现。

## 7. 已知限制与改进方向

| 项 | 现状 | 改进方向 |
| --- | --- | --- |
| 测速精度 | 50ms M 法，低速脉冲数少 | 缩短测速周期或改 M/T 法 |
| 循迹环与速度环未级联 | `Track_LF04` 直接输出 PWM，速度闭环调用保留在注释中 | 外环差速 + 内环速度串级，提升匀速性 |
| 直角消抖用阻塞延时 | `system_delay_ms(50)` 阻塞控制节拍 | 改为状态机非阻塞延时 |
| 十字路口处理 | 注释设计为"停 2s 鸣笛后直行"，实现仅直行 | 补齐蜂鸣器与计时逻辑 |
| KEY3 占用 A23 | 属主板风险引脚 | 迁移至安全引脚 |
| 无线调参命令 | 解析框架已留，赋值被注释 | 接通 PID 参数在线写入 |

## 9. 复现与使用

1. 用 Keil MDK 打开 `project/keil/SeekFree_MSPM0G3507_Device_Library.uvprojx`，编译下载。
2. 上电后 TFT 显示 `System Ready`，按任意按键唤醒菜单。
3. 菜单操作：K1/K2 移动光标，K3 确认/动作，K4 减操作；主页面可设圈数（Laps）、切换发车（Car: R/S）、向 OpenMV 下发 Task2~5、进入 Adjust 页调节 LAB 阈值。
4. 发车后小车按 LF04 循迹行驶，每过 4 个直角计一圈，跑满设定圈数自动停车。
5. 波形描绘功能（正弦/余弦/三角/方波）在 `servo.c` 中独立提供，按需在主循环直接调用。
6. 串口 0 输出运行数据（左右 PWM、偏差、直角计数），可接串口助手或 VOFA 观测。
