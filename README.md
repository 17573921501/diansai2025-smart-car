# 2025 电赛智能小车系统（MSPM0G3507）

2025 年全国大学生电子设计竞赛参赛项目。基于 **TI MSPM0G3507**（Cortex-M0+ @ 80MHz）与逐飞科技开源库，实现循迹行驶、直角弯识别定圈停车、OpenMV 视觉任务协同、TFT 菜单现场调参、双舵机云台波形描绘等功能。

## 功能特性

- **循迹控制**：LF04 四路灰度传感器状态机 + 位置式 PD 差速，支持直角弯/大弯/微调/十字路口/丢线保护
- **定圈停车**：直角弯计数 ×4 = 圈数判定，跑满自动停车，圈数菜单可调
- **速度闭环**：双编码器 EXTI 四倍频计数 + M 法测速 + 增量式 PI（Kp/Ki 可调）
- **视觉协同**：UART 自定义帧协议（AA 55 帧头 + 校验）下发任务命令、在线调节 K230 颜色阈值
- **人机交互**：TFT180 + 4 按键两级菜单（发车/圈数/任务/调参），免改代码适应现场光线
- **云台描绘**：X/Y 双舵机参数化轨迹——正弦、余弦、三角、方波
- **姿态感知**：IMU660RA（SPI）Z 轴低通滤波积分测方位角
- **调试链路**：printf 运行数据 + VOFA 无线串口波形调参

## 快速开始

1. Keil MDK 打开 `project/keil/SeekFree_MSPM0G3507_Device_Library.uvprojx`，编译下载（J-Link）。
2. 上电按任意键唤醒菜单：K1/K2 选择，K3 确认，K4 减操作。
3. 设定圈数后发车（Car: R），小车自动循迹并在跑满圈数后停车。
